# 《纸牌建筑师》关卡编辑器使用教程

这份教程面向关卡制作者，按照“准备蓝图 → 创建关卡 → 编排教学 → 试玩 → 发布”的顺序说明编辑器。第一次使用时，建议先照着文末的“A 字架教学关卡示例”完整做一遍。

---

## 一、先理解关卡由什么组成

一个关卡由四部分组成：

1. **目标蓝图**：玩家要搭成什么结构。
2. **建造规则**：可用多少张牌、目标高度是多少。
3. **测试规则**：建筑完成后接受稳定、风力或落物测试。
4. **教学导演**：按顺序提示玩家点击什么、按什么键、完成哪一步。

关卡保存时会复制一份完整蓝图到关卡文件中。之后即使删除或修改个人蓝图，已保存的关卡也不会消失或改变。

## 二、推荐的制作流程

不要一开始就在关卡编辑器里填写所有内容。推荐顺序如下：

1. 在自由搭建中搭好目标建筑。
2. 打开蓝图工作台，把建筑制作成蓝图并整理步骤。
3. 确认每个蓝图步骤的卡牌和推荐预设正确。
4. 回到主菜单，打开“关卡编辑器”。
5. 使用该蓝图创建关卡。
6. 设置测试和教学时间线。
7. 从每个关键教学节点试玩。
8. 完整通关一次，再发布关卡。

蓝图决定“搭什么”，关卡编辑器决定“为什么搭、如何教、怎样判定通过”。

## 三、创建关卡

从主菜单进入：

> 关卡编辑器 → 创建关卡

### 1. 基本信息

| 设置 | 作用 | 建议 |
|---|---|---|
| 关卡名称 | 关卡库和游戏 HUD 显示的名称 | 使用短而直接的名字，如“A 字架入门” |
| 关卡说明 | 告诉玩家最终目标 | 只说明目标，不要把操作教程全部写在这里 |
| 作者 | 导出和分享时记录制作者 | 第一次填写后会在本机记住 |
| 来源 | 玩家关卡或官方关卡 | 普通制作选择“玩家关卡” |
| 标签 | 用于分类 | 建议 2～4 个，如“教学、A字架、稳定” |

当前编辑器会把中文输入同时写入中英文文本字段，因此切换英文界面时暂时仍可能显示中文。

### 2. 目标蓝图

选择一份已经制作好的蓝图。保存关卡后，这份蓝图的独立副本会嵌入关卡。

“通关前必须完成内嵌蓝图”表示：

- 开启：玩家必须按照蓝图搭建，蓝图未完成时不能开始测试。
- 关闭：玩家可以自由设计结构，只要满足牌数、高度和测试要求即可。

教学关卡通常开启；鼓励创造的挑战关卡可以关闭。

注意：最多牌数不能小于蓝图本身的牌数，否则关卡无法正常完成和发布。

### 3. 建造规则

| 设置 | 含义 |
|---|---|
| 最少牌数 | 少于这个数量时不能开始测试 |
| 最多牌数 | 玩家在本关能够放置的牌数上限 |
| 目标高度层数 | HUD 中要求达到的建筑高度 |
| 测试秒数 | 当前测试需要坚持多久 |

“目标高度层数”不是直接填写世界坐标高度。填写 `1` 表示一层结构的参考高度，填写 `2` 表示两层。

### 4. 测试类型

#### 稳定性

不施加额外外力，只检查建筑能否在物理模拟中保持站立。

适合：A 字架、基础支撑、第一节教学。

#### 风力

测试期间持续给建筑施加风力。

适合：有屋顶的一层房屋、两层及更高建筑。新手关卡应使用轻风，避免玩家刚学会搭建就连续失败。

#### 落物冲击

从建筑上方投下重物。

| 参数 | 含义 |
|---|---|
| 重物质量 | 重物的质量，越大冲击越强 |
| 下落高度 | 重物相对目标建筑顶部的额外高度 |

适合：一层承重结构、屋顶和支撑力教学。

### 5. 多阶段测试

点击“添加测试阶段”，可以让同一个建筑连续接受多种测试。例如：

1. 先静置 3 秒，检查自身稳定。
2. 再吹轻风 5 秒。
3. 最后接受一次落物冲击。

前一阶段失败后不会进入下一阶段。新手关卡建议只使用一个测试，综合挑战再使用多阶段测试。

### 6. 评分参数

| 设置 | 作用 |
|---|---|
| 通关基础分 | 通过测试后获得的固定分数 |
| 每张节省牌奖励 | 少用一张牌增加多少分 |
| 每单位高度奖励 | 超过目标高度后获得的额外分数 |

教学关卡不要过度强调省牌和高度，否则玩家可能为了高分偏离你想教授的结构。

## 四、教学导演

教学导演是一条从上到下执行的线性时间线。玩家完成当前节点的条件后，系统才进入下一个启用节点。

### 1. 入场设置

| 设置 | 含义 |
|---|---|
| 入场标题 | 进入关卡时显示的大标题 |
| 入场副标题 | 一句话说明这一关要学什么 |
| 每个发布版本首次显示 | 玩家看完后不再自动播放；关卡重新发布新版本后再次播放 |
| 每次进入都显示 | 每次进入关卡都从头播放 |
| 入场自动关闭 | 填 `0` 时玩家点击开始；大于 `0` 时若干秒后自动关闭 |
| 允许玩家跳过 | 显示“跳过教学”按钮 |

正式新手关卡推荐“每个发布版本首次显示、允许跳过、手动开始”。

### 2. 教学节点通用操作

每张时间线卡片顶部包含：

| 控件 | 作用 |
|---|---|
| 勾选框 | 临时启用或禁用节点，禁用不会删除内容 |
| ↑ / ↓ | 调整节点顺序 |
| ⧉ | 复制当前节点 |
| ▶ | 从这个节点开始试玩 |
| × | 删除节点 |

“从此节点试玩”会启动一个新的试玩场景。如果该节点之前需要完成若干蓝图步骤，编辑器会自动放置前置步骤中的牌，但不会替玩家完成当前要学习的步骤。

自动准备的牌仍然遵循正常 Rapier 物理，不会被永久锁定。因此前置结构本身必须合理稳定。

### 3. 十种节点类型

#### 引导语句

显示一条普通说明，玩家点击“知道了”后进入下一节点。

适合：解释一个新的物理概念，或在操作之间做短暂总结。

不要连续使用很多引导语句。能用箭头和实际操作表达的内容，就不要写成长段文字。

#### 点击预设

等待玩家选中指定的放置预设，并自动指向预设按钮。

适合：“先选择短边直立 · 后倾 10°”。

如果玩家进入节点前已经选中了目标预设，节点会直接完成。

#### 选择工具

等待玩家切换到建造、推拨、删除或弹射工具。

适合第一次介绍工具栏，不建议每次切换工具都做一个节点。

#### 按键操作

等待玩家执行指定输入动作。界面显示的是玩家当前键位设置，而不是写死的字母。

适合：锁定高度、旋转卡牌、撤销、打开姿态轮盘。

#### 放置卡牌

等待玩家在该节点开始后新放置指定数量的牌。

例如填写 `2`，表示玩家进入这个节点后需要再放两张牌。自动准备的前置牌不会计入这个数量。

#### 完成蓝图步骤

等待指定蓝图步骤匹配成功。系统会把引导光圈投影到该步骤的第一张目标牌附近。

如果已经完成的牌倒塌或离开目标，蓝图进度回退，教学导演也会退回到最早未完成的蓝图教学节点。

#### 达到高度

等待建筑实时高度达到设置值。这里填写的是物理世界中的实际高度，不是“层数”。

通常只在需要明确教授“向上搭建”时使用；普通关卡可以直接依靠关卡目标高度。

#### 开始测试

等待玩家点击测试并进入倒计时或测试阶段。视觉目标默认指向测试按钮。

#### 测试成功

等待本关测试成功。适合显示通关前的任务描述，例如“让 A 字架稳定坚持 3 秒”。

#### 测试失败

等待测试失败。可以用来制作失败后的教学补救，例如提示玩家检查对称性和接地角度。

当前时间线没有条件分支。如果你把“测试成功”和“测试失败”连续放在同一条必经时间线上，其中一条会永远无法完成。第一版关卡应只选择其中一种作为必经节点。

### 4. 视觉指向目标

不由节点类型自动确定目标时，可以手动选择：

- 不指向。
- 高度锁定提示。
- 物理开关。
- 撤销或重做。
- 测试按钮。
- 场景坐标。

预设、工具和蓝图步骤会自动使用对应语义目标，不需要手填屏幕坐标。系统会跟随窗口尺寸、UI 缩放和目标位置变化。

“场景坐标”使用 `X / Y / Z` 世界坐标。适合指向地板上的建造区域、落物位置或结构的某个局部。建议通过试玩反复确认坐标。

绿色圆点和“语义目标有效”表示当前目标引用存在；红色提示表示目标需要重新选择。

### 5. 初始高亮

| 样式 | 适合用途 |
|---|---|
| 脉冲 | 温和提示普通按钮 |
| 箭头 | 明确要求点击某个控件 |
| 聚光 | 第一次介绍关键功能，压暗其他区域 |
| 按键徽章 | 强调键盘操作 |
| 蓝图发光 | 强调 3D 蓝图目标 |

不要每一步都使用聚光，否则玩家会感觉频繁被打断。

### 6. 渐进提示

每个节点默认有三级提示：

1. `3 秒`：轻微脉冲。
2. `8 秒`：显示更明确的箭头。
3. `15 秒`：使用聚光或更强的提示。

每一级都可以修改时间、视觉样式和提示文字。提示文字留空时，只增强视觉效果，不增加额外文字。

推荐写法：

- 节点主文本：“放置第一张支撑牌。”
- 8 秒提示：“选择蓝色高亮的预设。”
- 15 秒提示：“让短边贴地，并向结构中心倾斜。”

当玩家尝试相关操作时，停滞计时会重新开始，避免玩家正在思考或调整时立刻弹出最强提示。

### 7. 完成反馈

- 完成闪光：目标完成时显示短暂绿色反馈。
- 完成音效：播放现有成功提示音。

普通操作节点建议同时开启。连续非常快的节点可以关闭部分音效，避免声音过密。

### 8. 试玩事件日志

展开“试玩事件日志”可以查看最近的教学事件，例如：

- 节点开始。
- 节点完成。
- 玩家执行了哪个输入动作。
- 蓝图步骤回退。
- 玩家跳过教学。

日志主要用于排查“为什么节点没有前进”或“为什么节点被提前完成”。从游戏返回编辑器后即可查看最近记录。

## 五、试玩、验证和发布

### 1. 从节点试玩

使用节点上的 `▶`，快速验证：

- 箭头是否指向正确目标。
- 提示出现的时机是否正确。
- 前置蓝图结构是否准备正确。
- 当前节点能否被预期操作完成。

### 2. 完整试玩

在关卡库点击“试玩”，从头完成一次完整流程。重点检查：

1. 入场说明是否简短。
2. 玩家是否知道第一步该做什么。
3. 蓝图步骤是否会因为物理倒塌而回退。
4. 达到条件后能否开始测试。
5. 所有测试阶段能否正常结束。

试玩成功后，关卡库会显示“已试玩”。修改关卡或替换内嵌蓝图后，需要重新试玩。

### 3. 发布

关卡库中草稿关卡会显示“发布”按钮。以下问题会阻止发布：

- 缺少名称。
- 牌数上下限无效。
- 蓝图牌数超过关卡上限。
- 测试阶段参数无效。
- 教学节点缺少文本、目标或完成条件。
- 蓝图步骤没有覆盖所有目标牌。
- 内嵌蓝图校验失败。

当前版本允许发布尚未完整试玩的关卡，但会标记为“尚未试玩验证”。正式对外分享前仍应完成一次完整试玩。

每次重新发布，`publishRevision` 都会增加。选择“每个发布版本首次显示”的教学，会在新版本中重新向玩家展示。

## 六、关卡库功能

| 功能 | 说明 |
|---|---|
| 试玩 | 使用正式挑战逻辑运行关卡 |
| 编辑 | 修改关卡内容；已发布关卡修改后会重新成为草稿 |
| 复制 | 创建玩家关卡副本，适合制作难度变体 |
| 发布 | 校验并增加发布版本号 |
| 导出 | 生成 `.paker-level.json` 文件用于备份和分享 |
| 导入 | 从关卡文件导入；ID 冲突时会生成新的 ID |
| 删除 | 删除玩家关卡 |
| 恢复默认 | 删除官方关卡的本地修改，恢复项目内置版本 |

编辑官方关卡时，游戏保存的是一份本地覆盖版本，不会直接修改项目中的官方资源文件。

## 七、完整示例：制作 A 字架教学关卡

### 准备蓝图

先制作一份包含两张牌、两个步骤的蓝图：

1. 步骤一：放置第一张向中心倾斜的牌。
2. 步骤二：放置另一张牌，合拢成 A 字架。

为两个步骤分别记录正确的推荐放置预设。

### 创建关卡

- 名称：`A 字架入门`
- 说明：`使用两张牌搭建一个能够独立站立的 A 字架`
- 最少牌数：`2`
- 最多牌数：`2`
- 目标高度层数：`1`
- 测试：稳定性 `3 秒`
- 必须完成内嵌蓝图：开启

### 编排教学时间线

建议节点如下：

1. **引导语句**：`牌依靠接地摩擦力保持站立。`
2. **点击预设**：`选择向结构中心倾斜的短边直立预设。`
3. **完成蓝图步骤 1**：`放下第一张支撑牌。`
4. **点击预设**：选择另一侧对应的倾斜预设。
5. **完成蓝图步骤 2**：`让两张牌在顶部互相支撑。`
6. **开始测试**：`松开物理，让结构自己站稳。`
7. **测试成功**：`让 A 字架稳定坚持 3 秒。`

教学理念只说一次，然后立刻让玩家操作。第二张牌不需要再解释摩擦力，玩家会通过结构站稳得到即时反馈。

### 试玩检查

- 从步骤 2 和步骤 4 分别点击 `▶`。
- 确认对应预设高亮正确。
- 确认从步骤 4 开始时，第一张牌已经自动准备。
- 确认第一张牌倒下后，教学会回退。
- 最后从关卡库完整试玩并发布。

## 八、常见问题

### 为什么点击“从此节点试玩”后没有自动搭完整栋建筑？

该功能只准备当前节点之前必要的蓝图步骤。当前节点要求玩家完成的牌会故意留下，便于测试教学操作。

### 为什么自动准备的牌会倒？

自动准备不会锁定物理。请先检查蓝图前置结构是否真实稳定、牌的摩擦和姿态是否合理。

### 为什么节点一出现就自动跳过去？

预设、工具和高度节点会检查当前状态。如果玩家在进入节点前已经满足条件，节点会立即完成。需要玩家重新执行一次时，可以改用“按键操作”或重新安排节点顺序。

### 为什么按键教学显示的键和我写的不一样？

按键节点显示玩家当前绑定的键位，这是设计行为。教学文本中不要写死“按 F”或“按 Space”，应写“开启物理”或“锁定高度”。

### 为什么蓝图教学步骤不前进？

检查：

1. 关卡是否启动了内嵌蓝图引导。
2. 节点选择的蓝图步骤是否正确。
3. 卡牌位置、角度、接地边和高度是否在蓝图容差内。
4. 试玩事件日志中是否出现蓝图步骤回退。

### 为什么发布时提示教学步骤不完整？

常见原因包括：

- 节点主文本为空。
- 点击预设节点没有选择预设。
- 按键节点没有选择输入动作。
- 蓝图步骤索引已经因为替换蓝图而失效。
- 三级提示时间相同或没有按递增顺序排列。
- 场景坐标不是有效数字。
- 两个节点使用了重复 ID。

### “首次显示”为什么又出现了？

教学记录和发布版本绑定。重新发布关卡后版本号增加，新版本会重新显示教学，这是为了让作者能够教授更新后的内容。

### 测试成功和测试失败能否做分支？

当前 P2 教学导演只有线性时间线，没有条件分支。不要把成功和失败节点都放进同一条必经流程。分支教学属于后续版本功能。

## 九、新手教学设计原则

制作教学关卡时遵守以下原则：

1. 一次只教一个概念。
2. 先让玩家操作，再补充原理。
3. 主提示尽量控制在一句话内。
4. 使用箭头和蓝图轮廓代替方向性长文字。
5. 失败后指出一个可修正的原因，不要只说“失败”。
6. 每完成一张关键牌就给即时反馈。
7. 第一关教摩擦，第二关教对称，之后再教竖直支撑和高度。
8. 教学必须允许跳过，也必须能够重新播放。
