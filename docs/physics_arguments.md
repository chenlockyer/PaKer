“阻尼”可以理解为对运动的持续刹车。它与摩擦不同：摩擦主要发生在接触面之间；阻尼即使卡牌在空中也会持续降低速度。Rapier 官方也把它描述为模拟空气阻力等效果的手段。[Rapier 阻尼说明](https://rapier.rs/docs/user_guides/javascript/rigid_body_damping/)

## 各项参数的影响

| 参数 | 调高后的效果 | 当前值 | 建议起点 |
|---|---|---:|---:|
| 卡牌质量 | 更抗风、同样冲量下飞得更慢、撞击动量更大 | 0.10 | 0.08–0.12 |
| 卡牌摩擦 | 牌与牌、牌与地板更不容易滑动 | 1.00 | 0.90–1.00 |
| 地板摩擦 | 卡牌底边更难在地面滑动 | 1.10 | 1.00–1.10 |
| 最小弹射冲量 | 最轻的一次弹射也更有力 | 0.25 | 0.10–0.20 |
| 最大弹射冲量 | 满力度弹射速度更高、破坏力更强 | 2.45 | 1.50–2.00 |
| 结构线性阻尼 | 卡牌平移和滑动更快停下 | 0.50 | 0.25–0.40 |
| 结构角阻尼 | 卡牌晃动、倾倒和旋转更快停止 | 0.50 | 0.35–0.50 |
| 飞行线性阻尼 | 飞出去后更快损失前进速度 | 0.08 | 0.08–0.14 |
| 飞行角阻尼 | 飞镖自旋、投手翻转更快停止 | 0.08 | 0.03–0.08 |
| 推拨最大冲量 | 微调卡牌时推得更重 | 0.45 | 0.15–0.25 |
| 力度条单程时间 | 力度条移动更慢、更容易控制 | 1.20秒 | 1.30–1.60秒 |

### 卡牌质量

现实中一张纸牌通常约为 `1.7–2克`，即 `0.0017–0.002 kg`。[纸牌尺寸与重量参考](https://www.boxetto.com/what-is-the-standard-playing-card-size-dimensions-and-weight/)

但不能直接把游戏设置成 `0.002`。你的游戏中卡牌尺寸是 `1.8 × 2.6` 个世界单位，并非现实中的米制比例；风力与弹射冲量也按游戏尺度设计。如果直接使用现实质量，当前风力和弹射会显得极其巨大。

质量主要遵循：

```text
速度变化 ≈ 冲量 ÷ 质量
```

当前质量 `0.1`、最大冲量 `2.45`，理论速度变化可达到约 `24.5` 世界单位/秒，因此现在的满力度弹射偏强。

在你的代码中风对每张牌施加的是近似固定力，所以增加质量确实会让牌更抗风。

### 摩擦力

Rapier 中摩擦系数：

- `0`：完全没有摩擦。
- `1` 左右：已经属于很强的摩擦。
- 可以超过 `1`。[Rapier 摩擦参数](https://pmndrs.github.io/react-three-rapier/interfaces/ColliderProps.html#friction)

你的游戏使用 `Multiply` 组合规则，因此实际接触摩擦为：

```text
牌与牌 = 卡牌摩擦 × 卡牌摩擦
牌与地板 = 卡牌摩擦 × 地板摩擦
```

当前参数意味着：

```text
牌与牌：1.0 × 1.0 = 1.0
牌与地板：1.0 × 1.1 = 1.1
```

这属于偏稳定、偏玩法友好的设置，不算真实纸牌那样光滑。

如果想更接近涂层纸牌：

```text
卡牌摩擦：0.75
地板摩擦：0.90
牌与牌实际摩擦：0.5625
牌与地板实际摩擦：0.675
```

但这会显著提高搭建难度。比较适合游戏的折中值是：

```text
卡牌摩擦：0.95
地板摩擦：1.05
```

### 结构阻尼

结构线性阻尼控制：

- 滑动
- 平移漂移
- 碰撞后的横向运动

结构角阻尼控制：

- 摇晃
- 倾倒速度
- 碰撞后的旋转
- 建筑多久恢复安静

阻尼太高时，牌会像处于黏稠液体中，建筑虽然稳定，但缺少真实的惯性。阻尼太低则容易长时间晃动、滑动和旋转。

当前 `0.5 / 0.5` 偏稳定。建议先尝试：

```text
结构线性阻尼：0.30
结构角阻尼：0.40
```

### 飞行阻尼

飞行阻尼是弹药牌离开发射结构后的“空气阻力替代品”。

- 线性阻尼太高：炮弹和弩箭飞不远。
- 线性阻尼太低：像在真空中飞行。
- 角阻尼太高：飞镖很快停止自旋，投手牌也无法翻转。
- 角阻尼太低：卡牌旋转时间过长。

建议：

```text
飞行线性阻尼：0.10
飞行角阻尼：0.05
```

这会让平移能量稍快衰减，但保留飞镖和投手需要的旋转。

## 我推荐的“真实感但仍可玩”方案

```text
卡牌质量：0.10
卡牌摩擦：0.95
地板摩擦：1.05

最小弹射冲量：0.15
最大弹射冲量：1.80

结构线性阻尼：0.30
结构角阻尼：0.40

飞行线性阻尼：0.10
飞行角阻尼：0.05

推拨最大冲量：0.20
力度条单程时间：1.40秒
```

这套设置相比当前版本会：

- 降低“牌被黏住”的感觉。
- 保留纸牌屋需要的基本稳定性。
- 降低满力度弹射的夸张速度。
- 让飞镖继续保持自旋。
- 让推拨更适合精细调整。
- 力度条更容易控制。
