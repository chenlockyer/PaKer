# 关卡编辑器开发方案

实际操作方法见：[关卡编辑器使用教程](./关卡编辑器使用教程.md)。

## 定位

官方关卡与玩家关卡共用同一套数据格式和编辑器。区别仅在来源、发布权限和分发位置，不维护两套运行逻辑。

## 当前 MVP

- 从个人蓝图或官方教学蓝图创建关卡。
- 编辑名称、说明、作者、标签和来源类型。
- 编辑最少/最多牌数、目标高度和测试时间。
- 支持稳定性、风力、落物冲击三种测试。
- 保存时深拷贝完整蓝图到关卡，不依赖个人蓝图库。
- 记录来源蓝图 ID，仅用于追溯。
- 使用校验值检测内嵌蓝图损坏或篡改。
- 本地关卡库、导入、导出、删除和一键试玩。
- 试玩时复用正式挑战物理与结算流程，并启动内嵌蓝图引导。
- 编辑已有草稿，主动替换内嵌蓝图，复制关卡进行改造。
- 将稳定性、风力和落物测试编排为连续的多阶段测试。
- 任何编辑都会撤销旧试玩认证，只有实际通关且校验通过才能发布。
- 教学导演使用线性模板时间线，支持消息、预设、工具、按键、放牌、蓝图步骤、高度与测试事件。
- 教学节点支持语义 UI 目标、世界坐标、动态键位、3/8/15 秒渐进提示及完成反馈。
- 可以从任意教学节点试玩；编辑器自动准备必要的前置蓝图状态，但保持正常 Rapier 物理。
- 教学完成状态按关卡 ID 与发布版本记录，关卡更新后可以重新触发。
- 关卡格式已升级至 schema v2，并自动迁移旧版四类教学步骤。

## 数据原则

草稿和发布文件都必须自包含。任何关卡运行时只能读取 `embeddedBlueprint`，不得通过 `sourceBlueprintId` 回查个人蓝图库。

更新源蓝图不会静默改变已有的关卡。后续加入“替换关卡蓝图”操作时，必须重新生成校验值并要求重新试玩。
